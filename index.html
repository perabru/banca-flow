ÁREA RESTRITA

Bem-vindo de volta

Acesso exclusivo aos professores cadastrados.

Os acessos são criados pela administração. Não existe cadastro público.

Primeiro acesso · configurar o Firebase

1. Publique este único HTML em HTTPS (Firebase Hosting ou outro servidor estático). Habilite Authentication → E-mail/senha e autorize o domínio em Authentication → Configurações.

2. No Firebase Console, em Realtime Database → Regras, publique as regras de segurança incluídas neste HTML antes de cadastrar ou importar qualquer nota. Atenção: confira se a instância não contém dados de outro sistema antes de substituir as regras.

3. Em Authentication → Usuários, crie uma conta com e-mail e senha para cada professor. Copie cada UID. No Realtime Database → Dados, crie o nó users com cada UID como chave e os campos name, email, role e key. Somente Alberson terá role: "coordinator"; os outros terão role: "teacher". Use as chaves abaixo (não são senhas):

Alberson: alberson · Adriana: adriana · Bruno: bruno · Hélio: helio · Wagner: wagner · Fábio: fabio · José Eduardo: jose-eduardo

Exemplo de perfil em users/UID_DO_ALBERSON:

{"name":"Prof. Alberson","email":"EMAIL_REAL","role":"coordinator","key":"alberson"}

4. Entre como Alberson → Professores → Importar grupos protegidos. Use a senha de importação enviada separadamente com o arquivo. Após importar, crie as bancas e distribua as avaliações.

Nenhuma conta é criada pelo HTML; senhas, credenciais administrativas e regras não são protegidas se colocadas somente no navegador. Não adicione chaves de conta de serviço a este arquivo.
