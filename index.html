Acesso dos professores

Acesso exclusivo aos professores cadastrados.

Os acessos são criados pela administração. Não existe cadastro público.

Ajuda para liberar o acesso

E-mail e senha são verificados antes das permissões do sistema. Se a conta entrar, mas o acesso for negado, a administração precisa conferir o cadastro e as regras no Firebase.

Para liberar o Prof. Alberson:

  1. No Console do Firebase, abra o projeto avaliadortcc e confirme a conta dele em Authentication → Usuários. Copie o UID dessa conta.
  2. Em Realtime Database → Regras, publique a política deste arquivo. Use o banco avaliadortcc-default-rtdb, que está conectado ao sistema.
  3. Em Realtime Database → Dados → users → UID da conta do Alberson, confira os campos abaixo. Use o UID, não o nome nem o e-mail, como chave do perfil. Preserve os outros professores e os dados existentes.
{
  "name": "Prof. Alberson",
  "email": "E-MAIL DA CONTA DO ALBERSON",
  "role": "coordinator",
  "key": "alberson",
  "active": true
}

Esse perfil é exclusivo da conta do Alberson e deve ser configurado pela administração no Console. Os demais professores usam role: "teacher". Atualizar o HTML não publica as regras nem altera o perfil no banco.

Depois de publicar as regras e conferir o perfil, clique em Verificar acesso novamente ou entre com a conta do Alberson.
